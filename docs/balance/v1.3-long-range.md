# v1.3 balance: the Ver plane, the Twee-Twee and the long-range maps (D-036)

500 seeds per bot, pointer input, Classic mode on the Karoo (Monday layout for the bonus maps):
`npx tsx tools/balance-sim.ts --seeds 500 [--layout mon --bonus …] [--weapon … --sight …]`.

**Before** = the first v1.3 pass (main 5aa4f31 for the unchanged guns and maps; the .22 rows from
the first PR B report: .22 scoreMul ver ×1.5 only, Nog Verder ×0.75, Die Verste ×0.65, and a
rifle bot that lowered its sight for crates and secret parts). **After** = the final numbers: the
bot shoots crates and secrets with a rifle too, .22 scoreMul near ×0.75 / mid ×0.75 / ver ×1.5,
Nog Verder ×0.6, Die Verste ×0.46, and Die Verste needs a scope (D-036 (11), (13)).

Gates: on Classic, the M3 gates (competent 2 500–4 500, plinker ≥ 25 % below competent, plinker
above random) for every gun. On the bonus maps, competent ≤ 4 500 for every gun that can enter.
On plain maps, the .22 stays below both shotguns with every sight.

iron / peep / scope, Die Verste 22.1.
